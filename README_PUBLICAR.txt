COMO PUBLICAR ESTE SITE

1) Ficheiros incluídos:
   - index.html
   - logo-aloeworld.jpg

2) Para testar:
   - Abra o ficheiro index.html no navegador.

3) Para publicar na Vercel:
   - Crie um repositório no GitHub.
   - Carregue estes dois ficheiros para a raiz do repositório.
   - Entre em https://vercel.com/new
   - Clique em "Continuar com GitHub".
   - Escolha o repositório.
   - Em Framework Preset, pode deixar "Other" ou "Static".
   - Clique em Deploy.

4) Para publicar no Netlify:
   - Entre em https://app.netlify.com/drop
   - Arraste a pasta aloeworld-perfis-lsf-site para a página.
